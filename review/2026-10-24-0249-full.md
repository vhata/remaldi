## Summary

Seven findings remain open: four verified P2 defects and one inspected
P2 command-policy defect are promoted to separate work. Two P3 protocol
hardening defects already recorded in TODO remain inventory. The new defects
affect explicit target selection, tab-closing policy, relative runtime paths
and the secret audit's concurrency and historical filename handling. No application fixes are included in this snapshot.

The automated foundation passes. This establishes neither live Vivaldi
acceptance nor an assurance that the secret audit detects every historical
credential; the historical filename finding demonstrates one blind spot.
No actual secret exposure was found by this review.

## Invariants

- An explicitly supplied target must resolve to that target or fail before
  dispatch; only an omitted target may select the privileged UI context.
- Client and daemon must resolve the runtime directory to the same absolute
  location before choosing locks, socket paths and the child's directory.
- Uncertain transmissions are never replayed. Complete-operation deadlines
  cover queueing, and cancelled queued mutations cannot execute later.
- Browser snapshots are derived state, bounded by TTL and invalidated by
  connection changes, raw operations and supported browser events.
- Friendly dispatch uses the committed command policy and validates the
  selected window in the same browser evaluation as the dispatch.
- Optional capability failures remain explicit; malformed upstream payloads
  should become structured errors rather than escaping Python exceptions.
- Secret-audit cache publication must tolerate simultaneous worktrees. A
  historical blob's arbitrary representative filename must not suppress
  scanning content that appeared under another relevant filename.
- Fake servers and isolated JavaScript stubs prove local logic only. Live
  browser effects, private data and browser lifecycle remain outside them.

## Findings

### Open and Moved

- `empty-explicit-target-defaults-to-ui` — **An empty explicit target sends a raw request to the UI target.** Bug · Open · Verified.
  - Where: `remaldi/browser.py:224` (`Browser.request`), with parameter
    acceptance at `remaldi/service.py:112` (`Service.dispatch`).
  - Severity: P2.
  - A caller passing `raw ... --target "$TARGET_ID"` with an empty variable
    reaches `(target or self.ui_target_id)`, which selects the privileged UI
    instead of rejecting the missing target. A synthetic WebSocket server
    received exactly one `Runtime.evaluate` request on the UI connection for
    `target: ""`. Default only for `None`, or reject empty target IDs before
    transmission.
  - Review backlog: `reject-empty-explicit-target`

- `close-tab-command-bypasses-window-denial` — **Allowed tab-closing commands can reach the denied window-closing operation.** Bug · Open · Read.
  - Where: `remaldi/commands.py:70` and line 287 (`REGISTERED_COMMANDS`),
    compared with line 405 (`DENIED`).
  - Severity: P2.
  - `COMMAND_CLOSE_TAB` and `COMMAND_TAB_STACK_CLOSE` pass Remaldi's policy.
    In installed Vivaldi 8.2.4133.94 static source, their handlers reach shared
    tab-closing logic that calls window close when the final unassigned tabs
    close and `vivaldi.tabs.never_close_last` is false; its packaged macOS
    default is false. Close-tab also directly closes non-tabbed windows.
    This reaches the operation denied because closing the last window may
    quit the browser. Deny these paths or enforce equivalent lifecycle guards.
    The committed list identifies 8.2.4133.84; browser handlers were inspected
    in .94, never executed, so neither visible closure nor quitting is claimed.
  - Static trace: installed `Resources/vivaldi/bundle.js` character offsets
    4853556/4869722 (registry), 215465/216317 (handlers), 209578 (shared
    close-page function), 211192 (window close), 272412 (`chrome.windows.remove`).
  - Review backlog: `guard-tab-close-window-lifecycle`

- `relative-runtime-splits-client-daemon` — **Relative runtime paths resolve to different sockets in the client and daemon.** Bug · Open · Verified.
  - Where: `remaldi/runtime.py:12` (`runtime_dir`) and
    `remaldi/client.py:82` (`start_service`, child directory at line 94).
  - Severity: P2.
  - From a temporary caller directory, set `REMALDI_RUNTIME_DIR` to a short
    relative path and `REMALDI_ENDPOINT=http://127.0.0.1:1`, then run
    `command list` with the checkout on `PYTHONPATH`. The client returns
    `startup_timeout` while the daemon is running at the path resolved from
    the package root; using that absolute path for `status` reports running.
    Normalize the runtime path before validation and propagate the absolute
    path to the child; check the socket length after normalization.
  - Review backlog: `normalize-runtime-directory`

- `secret-cache-shared-temporary-file` — **Concurrent clean audits can fail while publishing their shared cache.** Tooling · Open · Verified.
  - Where: `scripts/audit-secrets.py:121` (`main`, cache publication).
  - Severity: P2.
  - All worktrees share the Git common directory and the same cache `.tmp`
    filename. Two audits writing this file before either replaces it leave
    one process raising `FileNotFoundError` after the other renames it.
    A barrier-controlled reproduction with two real audit processes in a
    disposable repository made one clean audit exit 1. Use unique temporary
    files and atomic publication; serialize or merge updates if retaining
    both writers' cache additions is required.
  - Review backlog: `publish-audit-cache-concurrently`

- `historical-secret-filename-suppression` — **A historical rename to an excluded filename can hide a secret-bearing blob.** Security · Open · Verified.
  - Where: `scripts/audit-secrets.py:52` (`history_blobs`),
    `scripts/audit-secrets.py:108` (`main`, historical scan).
  - Severity: P2.
  - The history inventory keeps one path per blob, but detect-secrets applies
    filename exclusions. In a disposable repository, commit a synthetic
    keyword fixture as `config.py`, rename it to `poetry.lock`, then delete
    it. A cold audit reports one history blob and no findings when Git names
    that blob `poetry.lock`, although directly scanning `config.py` detects
    it. Preserve relevant path contexts or scan historical content without
    those filename exclusions. This reproduces a blind spot, not an actual
    credential exposure.
  - Review backlog: `scan-history-without-filename-blind-spots`

- `malformed-service-reply-escapes-client` — **Malformed service replies can escape as uncaught Python errors.** Bug · Open · Verified.
  - Where: `remaldi/client.py:34` (`exchange`, reply interpretation).
  - Severity: P3.
  - A temporary Unix-socket server replying with `[]` after reading a request
    causes `AttributeError` at `response.get`; missing object fields can
    similarly escape as `KeyError` or `TypeError`. Validate the reply envelope
    and report `protocol_mismatch`. A broken or mismatched service is required;
    the maintained daemon does not generate such replies.
  - Existing TODO: `client-malformed-response-errors`; inventory only.

- `malformed-devtools-payloads-escape-boundaries` — **Malformed DevTools payloads escape capability and structured-error handling.** Bug · Open · Verified.
  - Where: `remaldi/adapter.py:355` (`VivaldiAdapter.evaluate`),
    `remaldi/browser.py:177` (`Browser._probe_incognito`),
    `remaldi/browser.py:212` (`Browser._connection`),
    `remaldi/transport.py:34` (`CDPConnection._read`) and line 77 (`request`).
  - Severity: P3.
  - Synthetic evaluation results containing `result: 7` or `result: null`
    raise `TypeError` rather than `unsupported_result`. A fake WebSocket
    returning a top-level `result: []` for an incognito probe produces
    `endpoint_unavailable` and skips a valid regular candidate, because the
    shape read is outside the probe's exception handler. Inspection also
    confirms unchecked frame/result shapes in transport and hook setup.
    Validate at decoding boundaries and preserve the intended capability or
    protocol error. A nonconforming upstream response is required; no such
    live Vivaldi response was observed.
  - Existing TODO: `non-object-devtools-results`; inventory only.
